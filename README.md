# Portfólio — Luiz Gomes

Site estático (HTML + CSS + JS, sem build) publicado no Vercel.

- `index.html` — todo o conteúdo e estilos
- `assets/work/` — peças de design (Crossover Creative)
- `assets/img/` — retrato e imagem de compartilhamento

Para editar textos, abra `index.html`. Para adicionar trabalhos de design, coloque as imagens em `assets/work/<slug>-01.jpg` e inclua o item na lista `CASES` no final do arquivo.
